About Radio Registry

What is this?

Radio Registry is a privacy-focused radio station directory for Tor and I2P networks. This is the automatic mirroring version - cover art from submissions is automatically mirrored and hosted locally for privacy and reliability.

This is an open-source project you can run yourself to create your own radio station directory for anonymous networks.

Setting Up Your Own Instance

Prerequisites

  • Python 3.8 or higher
  • Tor service running (for Tor station validation)
  • I2P router with HTTP proxy (for I2P station validation)
  • A hidden service configured (.onion address)
  • Optional: I2P tunnel (.i2p address)

Quick Start

# Clone the repository
git clone [your-repo-url]
cd radio-registry

# Install dependencies
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

# Initialize the database
python -c "import database; database.init_db()"

# Configure your settings
# Edit config.py and set:
# - ADMIN_PASSWORD (change from default!)
# - ADMIN_SECRET_KEY (change from default!)
# - TOR_BASE_URL (your .onion address)
# - MIRRORS (your mirror URLs)

# Run the server
uvicorn main:app --host 127.0.0.1 --port 8080

Configuring Tor Hidden Service

Add to your /etc/tor/torrc:

HiddenServiceDir /var/lib/tor/radio-registry/
HiddenServicePort 80 127.0.0.1:8080

Restart Tor, then get your .onion address:

sudo cat /var/lib/tor/radio-registry/hostname

Setting Up Health Checks

Add a cron job to periodically check station health (runs every 5 minutes):

*/5 * * * * /path/to/venv/bin/python /path/to/checker.py >> /path/to/checker.log 2>&1

Admin Panel

Access the admin panel at /admin. Default password is set in config.py. Change it immediately after first login!

Enable 2FA for additional security by clicking "Setup 2FA" in the admin panel.

Important Security Notes

  • Change default passwords: Update ADMIN_PASSWORD in config.py
  • Change secret key: Generate a new ADMIN_SECRET_KEY
  • Enable 2FA: Add two-factor authentication via the admin panel
  • Firewall: Only expose port 8080 to localhost, not the internet
  • Reverse proxy: Run behind Tor hidden service or I2P tunnel

Customizing Your Instance

All major settings can be adjusted in config.py. Here are the most common customizations:

Health Check Settings

Control how often stations are checked and when they're marked offline or dead:

# In config.py

# How often to check online stations (default: every 4 hours)
HEALTH_CHECK_INTERVAL_HOURS = 4  # Set to 1 for hourly checks

# How long to wait for a response (default: 30 seconds)
HEALTH_CHECK_TIMEOUT = 30

# Escalating recheck intervals for failed stations (in minutes)
# Default: recheck at 5 min, 15 min, then 1 hour before confirming offline
RECHECK_INTERVALS_MINUTES = [5, 15, 60]

# When to mark a station as "dead" (default: 12 hours)
DEAD_THRESHOLD_HOURS = 12

Example configurations:

  • Faster checks: Set HEALTH_CHECK_INTERVAL_HOURS = 1 for hourly checks
  • More lenient: Set DEAD_THRESHOLD_HOURS = 24 to wait longer before marking dead
  • Quick failure detection: Set RECHECK_INTERVALS_MINUTES = [2, 5, 15]

API & Pagination

# Default stations per page
DEFAULT_PAGE_SIZE = 50

# Maximum allowed (prevents abuse)
MAX_PAGE_SIZE = 200

NSFW Detection

Cover art is automatically scanned using an ML model (~98% accuracy). The default threshold is 0.8 (80% confidence). To adjust sensitivity, modify the threshold in nsfw_scanner.py:

  • 0.9+: Very permissive (may miss some NSFW)
  • 0.8: Default, balanced
  • 0.6-0.7: More aggressive (may have false positives)

Note: The NSFW model is not perfect. Operators are responsible for all hosted content. See the README for full legal disclaimer.

Submitting Stations

Running a radio station on Tor or I2P? Submit it to the directory. Submissions are automatically validated and approved if the stream is valid.

Cover Art Privacy

All station cover art is automatically downloaded and mirrored locally. When a station is submitted with cover art, it is:

  • Downloaded through Tor (even for clearnet URLs)
  • Saved locally to prevent external tracking
  • Served via your Tor/I2P service
  • Limited to 8MB per image

API Access

The directory provides a JSON API for programmatic access:

  • GET /api/stations - List all stations
  • GET /api/stations?network=tor - Tor stations only
  • GET /api/stations?network=i2p - I2P stations only
  • GET /api/stations?genre=electronic - Filter by genre
  • GET /api/stations?online_only=true - Only online stations
  • GET /api/stations/{id} - Station details
  • GET /api/stations/{id}/cover - Station cover art
  • GET /api/stats - Directory statistics
  • GET /api/genres - List available genres
  • POST /api/submit - Submit a new station

Response Fields

healthStatus online | offline | dead
consecutiveFailures Number of failed checks in a row (0 when online)
lastCheckOk Boolean - true if last check succeeded
lastCheckTime ISO timestamp of last health check

Health Status: online = last check succeeded | offline = failed but was online within 12 hrs | dead = no response for 12+ hours
