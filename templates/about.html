About

What is this?

A directory and registry of I2P and Tor radio stations. Stations are health-checked with smart scheduling: online stations every 4 hours, failed stations get escalating rechecks (5min, 15min, 1hr) before being marked offline.

How to listen

On Android: Use any radio app that supports SOCKS5 proxy (for Tor) or HTTP proxy (for I2P). Apps like Orbot or InviZible Pro can provide system-wide proxy support.

On Desktop: Configure your media player (VLC, mpv, etc.) to use the Tor SOCKS proxy (localhost:9050) or I2P HTTP proxy (localhost:4444), then open the stream URL.

Submit a station

Running a radio station on Tor or I2P? Submit it to the directory. Submissions are automatic and not reviewed before being published.

Cover Art

All station cover art is mirrored and hosted locally for privacy and reliability. When a station is submitted with cover art, it is downloaded and served directly from our servers rather than fetching from external sources.

API

The directory provides a JSON API for programmatic access:

  • GET /api/stations - List all stations
  • GET /api/stations?network=tor - Tor stations only
  • GET /api/stations?network=i2p - I2P stations only
  • GET /api/stations?genre=electronic - Filter by genre
  • GET /api/stations?online_only=true - Only online stations
  • GET /api/stations/{id} - Station details
  • GET /api/stations/{id}/cover - Station cover art
  • GET /api/stats - Directory statistics
  • GET /api/genres - List available genres
  • GET /api/health - API health check
  • POST /api/submit - Submit a new station

Station Response Fields

healthStatus online | offline | dead
consecutiveFailures Number of failed checks in a row (0 when online)
lastCheckOk Boolean - true if last check succeeded
lastCheckTime ISO timestamp of last health check

Health Status: online = last check succeeded | offline = failed but was online within 12 hrs | dead = no response for 12+ hours
